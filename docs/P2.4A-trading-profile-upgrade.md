# P2.4A · 交易画像升级方案
> 把"交易记录页"升级成"AI 理解中心"
> 本文件只做方案，不改代码。

---

## 0. 一句话目标

用户每记录一笔交易，AI 就多了解他一点。
画像页让用户看到"AI 眼中的我"，而不是一张冷冰冰的统计表。

---

## 1. 页面结构

```
/journal（交易日志页）
│
├── [顶部] 画像完成度进度条
│   └── "你的 AI 画像已完成 60%，再记 3 笔即可解锁深度观察"
│
├── [区块 A] AI 观察卡（核心新增）
│   ├── 你最擅长的品种
│   ├── 你最常用的时间周期
│   ├── 你的胜率趋势
│   ├── 你的止损习惯
│   └── 你最近的状态变化
│
├── [区块 B] 最近 5 笔复盘入口（新增）
│   └── 每笔一行：品种 + 方向 + 盈亏 + [AI 复盘] 按钮
│
├── [区块 C] 数据统计面板（现有，保留）
│   ├── 总胜率 / 平均盈亏 / 最佳 / 最差
│   ├── 按策略分组
│   └── 按品种分组
│
└── [区块 D] 交易记录列表（现有，保留）
    └── 每笔可展开 / 编辑 / 删除
```

**布局原则：**
- 移动端：A → B → C → D 垂直堆叠
- 桌面端：A + B 左右并排，C + D 在下方
- AI 观察卡用深色卡片（区别于统计面板的浅色）

## 2. AI 观察卡字段

> 所有字段必须来自真实交易数据，没有数据的字段不显示，不猜测。

### 2.1 字段清单

| 字段名 | 显示标题 | 数据来源 | 最少需要几笔 |
|--------|----------|----------|-------------|
| `topSymbol` | 你最常交易的品种 | `Trade.symbol` 出现频率最高 | 1 笔 |
| `topSetup` | 你最常用的策略 | `Trade.setup` 出现频率最高 | 3 笔 |
| `winRateTrend` | 你的胜率趋势 | 最近 5 笔 vs 全部胜率对比 | 5 笔 |
| `avgHoldTime` | 你平均持仓多久 | `closedAt - openedAt` 均值 | 3 笔已平仓 |
| `stopLossHabit` | 你的止损习惯 | 有无填写 `stopPrice` 的比例 | 5 笔 |
| `bestSetup` | 你胜率最高的策略 | `bySetup` 中 winRate 最高 | 5 笔 |
| `weakSetup` | 你最容易亏损的策略 | `bySetup` 中 avgPnlPct 最低 | 5 笔 |
| `recentMood` | 你最近的状态 | 最近 3 笔的 pnlPct 均值 | 3 笔 |
| `longShortRatio` | 你做多还是做空更多 | `direction` 统计 | 5 笔 |
| `topTimeframe` | 你最常用的时间周期 | `Trade.timeframe` 频率最高 | 3 笔 |

### 2.2 字段展示格式（举例）

```
🎯 你最常交易的品种
   BTCUSDT（共 12 笔，胜率 58%）

⏱ 你平均持仓多久
   约 4 小时（属于日内交易风格）

📈 你的胜率趋势
   最近 5 笔胜率 60%，比整体高 8%，状态不错

🛡 你的止损习惯
   83% 的交易设置了止损，习惯较好

⚡ 你胜率最高的策略
   突破回踩（5 笔，胜率 80%）

⚠️ 你最容易亏损的策略
   FVG 填补（4 笔，平均亏 -2.3%）
```

> 原则：诚实告知，不编造，不用"暂无数据"这种冷漠词。

### 3.1 全局样本不足（< 3 笔已平仓）

```
📊 AI 还在认识你

你目前有 X 笔已平仓交易。
再记录 Y 笔，AI 就能开始观察你的交易习惯了。

每记一笔，AI 就多了解你一点。
```

### 3.2 单字段样本不足

| 字段 | 不足时显示 |
|------|-----------|
| 胜率趋势 | "需要至少 5 笔才能看出趋势，继续记录吧" |
| 最佳/最差策略 | "策略样本还不够，先多试几种策略" |

| 止损习惯 | "还没有足够数据，建议每笔都填写止损价" |
| 最近状态 | "最近 3 笔数据不足，继续记录" |

### 3.3 新用户第一次进入

```
👋 欢迎来到你的 AI 理解中心

这里会随着你的每一笔交易，
慢慢形成 AI 对你的了解。

不是统计报表，是 AI 真正认识你的过程。

[记录第一笔交易 →]
```

## 4. 画像完成度规则

> 用进度条显示，让用户有动力继续记录。

### 4.1 完成度计算

| 条件 | 加分 |
|------|------|
| 已有 ≥ 1 笔交易记录 | +10% |
| 已有 ≥ 3 笔已平仓 | +15% |
| 已有 ≥ 5 笔已平仓 | +15% |
| 已有 ≥ 10 笔已平仓 | +15% |
| 至少 3 笔填写了 `setup` | +10% |
| 至少 3 笔填写了 `stopPrice` | +10% |
| 至少 3 笔填写了 `timeframe` | +10% |
| 至少 3 笔填写了 `notes` | +10% |
| 至少 3 种不同 `setup` | +5% |

**满分 100%，上限 100%。**

### 4.2 进度条文案

| 完成度 | 文案 |
|--------|------|
| 0–20% | "AI 刚认识你，继续记录吧" |
| 21–40% | "AI 开始了解你的交易风格" |
| 41–60% | "AI 已经能看出一些规律了" |
| 61–80% | "AI 对你的了解越来越深" |
| 81–99% | "AI 画像接近完整，细节越来越准" |
| 100% | "AI 画像已完整，持续更新中" |

## 6. 聊天中如何引用画像

> 目标：让用户感受到"AI 真的认识我"，而不是每次都从零开始。

### 6.1 注入时机

- 每次发起聊天时，从数据库读取该用户的 `AggregateStats`
- 已有 ≥ 5 笔已平仓 → 注入画像摘要到 system prompt
- 已有 ≥ 10 笔已平仓 → 注入更完整的画像

### 6.2 注入内容格式（system prompt 片段）

```
【用户交易画像】
- 最常交易品种：BTCUSDT（12 笔，胜率 58%）
- 最常用策略：突破回踩（5 笔，胜率 80%）
- 平均持仓时长：约 4 小时（日内风格）
- 止损习惯：83% 的交易设置了止损
- 最近 5 笔胜率：60%（比整体高 8%）
- 最容易亏损的策略：FVG 填补（平均 -2.3%）
```

### 6.3 AI 引用画像的说话方式

**好的引用方式（自然、不突兀）：**
```
你之前做突破回踩胜率挺高的，这次 BTC 的结构
看起来也是类似的形态，可以参考一下你自己的经验。
```

```
你平时偏日内，这个位置如果要做，
建议用你熟悉的 1h 周期来确认一下。
```

**不好的引用方式（生硬、像在背数据）：**
```
❌ 根据你的交易画像，你的胜率是 58%，
   建议你参考你的历史数据进行决策。
```

### 6.4 引用触发条件

| 用户问题类型 | AI 是否引用画像 |
|-------------|----------------|
| 问某个品种行情 | 如果用户常交易该品种，提一句 |
| 问某个策略 | 如果用户有该策略记录，引用胜率 |
| 问"我该怎么做" | 结合用户风格给建议 |
| 纯市场分析问题 | 不强行引用，保持自然 |
| 闲聊 | 不引用 |

## 7. 最近 5 笔复盘入口设计

### 7.1 展示格式

```
┌─────────────────────────────────────────────────────┐
│ 最近 5 笔交易                              [查看全部] │
├─────────────────────────────────────────────────────┤
│ ● BTCUSDT  做多  +3.2%  2026-05-08  [AI 复盘]       │
│ ● EUR/USD  做空  -1.1%  2026-05-07  [AI 复盘]       │
│ ● BTCUSDT  做多  +0.8%  2026-05-06  [AI 复盘]       │
│ ● 黄金     做多  +2.1%  2026-05-05  [AI 复盘]       │
│ ● ETHUSDT  做空  -0.5%  2026-05-04  [AI 复盘]       │
└─────────────────────────────────────────────────────┘
```

### 7.2 [AI 复盘] 按钮行为

**TP-MAX / TP-ULTRA 用户：**
- 点击后跳转到聊天页（对应品种的 channel）
- 自动预填消息：
  ```
  帮我复盘一下这笔交易：
  品种：BTCUSDT，方向：做多，
  入场：92000，出场：94944，盈亏：+3.2%，
  策略：突破回踩，时间周期：1h
  ```
- AI 收到后直接开始复盘分析

**FREE 用户：**
- 点击后显示升级提示弹窗：
  ```
  🔒 AI 复盘需要 TP-MAX 或以上

  升级后，AI 会结合你的交易记录，
  帮你分析这笔交易的得失。

  [升级 TP-MAX →]  [暂不升级]
  ```

### 7.3 复盘消息模板（AI 收到后的处理）

AI 收到复盘请求后，按以下结构回复：

```
1. 这笔交易做对了什么（1-2 句）
2. 有什么可以改进的地方（1-2 句）
3. 结合你的历史习惯，给一个具体建议（1 句）
```

**不做：**
- 不评价用户的心理状态
- 不说"你下次一定能做好"这类鼓励话
- 不给出"下一笔应该做什么"的喊单建议

## 8. 风险点

### 8.1 数据风险

| 风险 | 描述 | 应对 |
|------|------|------|
| 样本太少误导用户 | 3 笔数据就说"你的胜率是 67%"，用户可能过度相信 | 所有字段标注样本数，< 10 笔加"样本较少，仅供参考" |
| 用户手动填错数据 | 入场价填错导致 pnlPct 异常 | 显示时做异常值过滤（pnlPct > 100% 或 < -100% 标红提示） |
| 画像注入 token 超限 | 画像太长导致上下文爆炸 | 画像摘要控制在 200 tokens 以内，超出截断 |

### 8.2 产品风险

| 风险 | 描述 | 应对 |
|------|------|------|
| 用户误以为 AI 在喊单 | "你胜率最高的策略是突破回踩"被理解为"去做突破回踩" | 所有观察卡加免责小字："以上为历史数据观察，不构成交易建议" |
| 用户对画像不满 | "AI 说我弱点是 FVG，但我觉得不对" | 加"这对你有帮助吗？"反馈按钮，收集用户信号 |
| 画像完成度游戏化过度 | 用户为了刷进度乱填数据 | 进度条只是引导，不与任何权益直接挂钩 |

### 8.3 技术风险

| 风险 | 描述 | 应对 |
|------|------|------|
| 画像计算性能 | 每次聊天都查全量 Trade 表 | 加 Redis 缓存，5 分钟 TTL；或只在画像页刷新时重算 |
| 复盘跳转丢失上下文 | 跳转到聊天页后预填消息丢失 | 用 URL query param 传递，聊天页读取后自动填入 |
| FREE 用户看到锁定内容 | 前端判断权限不严格 | 锁定字段在后端不返回，前端只做展示层判断 |

## 10. 补充建议：让画像真正形成护城河

> 核心问题：用户看完画像之后……然后呢？
> 现有方案把画像做成了"展示终点"，真正的护城河是让画像变成**持续使用的理由**。

### 建议 A：画像驱动的"今日提醒"（首页展示）

每次用户打开 App，首页显示一句从画像里提炼的个性化提醒：

```
💡 你今天的提醒
你最近 5 笔 FVG 填补平均亏 -2.3%，
今天如果看到 FVG 机会，多等一个确认信号再进。
```

- 不是喊单，是基于用户自己数据的提醒
- 完全来自 `weakSetup` 字段，不调用 AI，成本极低
- 每天都不一样，用户有理由每天打开

---

### 建议 B：画像"盲区"提示（引导数据质量）

用户填写不完整的字段，画像就有盲区。要让用户知道：

```
⚠️ 你的画像有 2 个盲区

• 你有 8 笔交易没有填写止损价
  → AI 无法判断你的风险控制习惯

• 你有 5 笔交易没有选择策略类型
  → AI 无法分析哪种策略最适合你

[去补充这些交易 →]
```

- 引导用户填写更完整的数据
- 数据越完整，画像越准，用户越依赖
- 这是真正的护城河：用户数据沉淀越多，越难离开

---

### 建议 C：复盘结论存回 `Trade.notes`（数据飞轮）

现在的复盘是"一次性的"。建议 AI 复盘后把关键结论追加到 `Trade.notes`：

```
用户点 [AI 复盘]
→ AI 分析："这笔你入场时机偏早，可以等 1h 收线确认"
→ 自动追加到 Trade.notes：
  "[AI 复盘 2026-05-09] 入场偏早，建议等 1h 收线"
```

- 复盘结论沉淀在数据里，下次画像更准
- 用户感受到"AI 真的在帮我积累经验"
- 竞品很难复制的数据飞轮

---

### 建议 D：月度快照卡（传播 + 留存）

每 30 天自动生成一张"本月交易总结卡"，用户可截图分享：

```
┌─────────────────────────────┐
│  📊 你的 5 月交易总结        │
│                             │
│  共 18 笔  胜率 61%          │
│  最佳策略：突破回踩 (80%)    │
│  进步最大：止损执行率 +15%   │
│                             │
│  AI 观察：你在做多方向       │
│  比做空稳定很多              │
│                             │
│  洞察AI · TradePilot        │
└─────────────────────────────┘
```

- 用户有分享动力 → 自然传播
- 用户会回来看下个月变化 → 留存
- 纯数据计算，不需要 AI 生成

---

### 建议 E：和自己的过去对比（参照系）

现在的画像只有绝对值，用户不知道"胜率 58% 是好还是坏"。
加一个时间维度对比：

```
胜率趋势：
上个月 52% → 本月 61% ↑ 进步了 9%
```

### 建议优先级

| 建议 | 价值 | 实现成本 | 优先级 |
|------|------|---------|--------|
| B：画像盲区提示 | 高（数据质量） | 低 | ⭐⭐⭐ 最先做 |
| A：今日提醒 | 高（日活） | 低 | ⭐⭐⭐ 最先做 |
| C：复盘存回 notes | 极高（数据飞轮） | 中 | ⭐⭐ 第二批 |
| D：月度快照 | 高（传播） | 中 | ⭐⭐ 第二批 |
| E：时间维度对比 | 中 | 低 | ⭐ 随时可加 |
